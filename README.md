# ひとりじゃない発表（ウェブ版）

発表者の手元の画面にだけ、小さな応援キャラが出てくる発表ツールです。
マイクとカメラから不安のサインを読み取って、必要なときだけ短い一言をふきだしで届けます。
聴衆の画面にはスライドしか映りません。

AIはユーザーのブラウザの中で動くので、サーバーもAPIキーも料金もいりません。

## 使い方

1. パソコン版の **Chrome** か **Edge** でページを開く
2. PowerPoint や Figma から書き出した **PDF** を読みこむ
3. 必要ならスライドの並べ替え・非表示・自分用メモを書く
4. 応援キャラを選ぶ（はじめは「Aちゃん」。好きな画像にも変えられます）
5. 初回だけ「AIをダウンロード」を押す（約1GB。次からはすぐ使えます）
6. Macの「システム設定 → ディスプレイ」でプロジェクターを **拡張表示** にする
7. 「発表をはじめる」を押す
   - 手元の画面：今のスライド・次のスライド・メモ・時間・応援キャラ
   - 新しく開いたウィンドウ：聴衆用のスライドだけの画面。プロジェクター側に移して「全画面にする」を押す
8. 矢印キー・スペース・クリッカーでスライドを送る

マイクとカメラの許可を聞かれたら「許可」を選んでください。

## GitHub Pages で公開する

1. GitHubで新しいリポジトリを作る（例：`hitorijanai`）
2. このフォルダの中身をすべてアップロードする（`index.html` がいちばん上に来るように）
3. リポジトリの **Settings → Pages** を開く
4. 「Branch」で `main` と `/ (root)` を選んで **Save**
5. 1〜2分で `https://ユーザー名.github.io/hitorijanai/` が使えるようになります

マイク・カメラ・AIは `https://` のページでしか動かないので、GitHub Pages はちょうど合っています。

## 手元のパソコンで試す

ファイルをダブルクリックで開くと動きません。ターミナルでこのフォルダに移動して、次のどちらかを実行します。

```
python3 -m http.server 8000
```

そのあと Chrome で `http://localhost:8000` を開きます。

## 不安のサインと調整

発表中に「センサー」ボタンを押すと、測っている数値が見られます。
リハーサルで確かめて、`js/buddy-ai.js` の `SIGNS` のしきい値を自分たちの環境に合わせてください。

| サイン | 見ているもの | 仮のしきい値 |
| --- | --- | --- |
| 長い沈黙 | マイクの音量 | 4秒以上 |
| 早口 | 音声認識の文字数 | 420字/分 以上 |
| 「えーと」が多い | 音声認識 | 8秒に2回以上 |
| 声のゆれ | 音量のばらつき | 0.6 以上 |
| 下ばかり見ている | カメラ（目線） | 60% 以上 |
| 目が泳ぐ | カメラ（目線） | 40回/分 以上 |
| まばたきが多い | カメラ（まばたき） | 35回/分 以上 |

サインの重みを足した「不安スコア」が 0.3 以上になったとき、最短20秒おきに声をかけます。
声をかけるタイミングはスコアが決め、言葉はAIがその場で考えます。

## プライバシー

- カメラの映像はブラウザの中だけで処理し、保存も送信もしません
- AIもブラウザの中で動くので、測った数値は外に出ません
- 「話す速さと『えーと』を数える」をオンにすると、音声は Chrome の音声認識サービスに送られます。気になるときはオフにしてください（沈黙・声のゆれ・目線は測れます）

## ファイル構成

```
index.html        準備画面と発表者の画面
audience.html     聴衆用の画面
css/style.css     デザイン
js/app.js         全体のまとめ役
js/audience.js    聴衆用の画面の動き
js/slides.js      PDFの描画（pdf.js）
js/voice.js       マイクの分析
js/gaze.js        カメラの分析（MediaPipe）
js/buddy-ai.js    不安のサインの判定と声かけ（WebLLM）
js/ai-worker.js   AIを別スレッドで動かす
img/a-chan.svg    既定のキャラクター「Aちゃん」
```

## 動く環境

- パソコン版 Chrome / Edge（AIには WebGPU が必要です。M1以降のMacなら快適に動きます）
- Safari や Firefox、古いパソコンでは AI の代わりに用意したことばで応援します
